## 中文

### 项目介绍
**EITFWH** 是一款面向**气动声学**领域的计算软件，基于 **Ffowcs Williams–Hawkings (FW-H)** 方程设计，用于模拟非定常流动产生的声波辐射与传播过程。  
该软件适用于由不同类型声源（**单极子、偶极子、四极子**）引发的声波计算，尤其在**流动噪声数值模拟**与工程应用中具有广泛适用性。

目前 FW-H 核心求解器全部基于 **C++** 开发，支持 **MPI 并行**，具备面向实际工程问题的应用潜力。

## English

### Project Overview
**EITFWH** is a computational software package for **aeroacoustics**, developed based on the **Ffowcs Williams–Hawkings (FW-H)** equation to model acoustic radiation and propagation generated by unsteady flows.  
It supports sound prediction induced by typical acoustic source mechanisms (**monopole, dipole, and quadrupole**) and is widely applicable to **flow-induced noise simulations** and engineering-oriented workflows.

The FW-H core solver is implemented in **C++** and supports **MPI parallelization**, demonstrating strong potential for real-world engineering applications.
